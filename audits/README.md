## How to check me in two minutes
Every number in the audit is reproducible: clone the repo, `bun install --frozen-lockfile`, run the two test
scripts side by side and compare the exit codes and timings. If a claim is not reproducible, it is labelled as
judgement rather than measurement — those sections are marked, and they are the part worth $69.
