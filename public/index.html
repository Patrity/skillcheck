skillcheck

Offline-style conformance check for Agent Skills SKILL.md. Paste one, see what a strict loader sees.

What this does and does not claim. A FAIL means a strict loader rejects the file (invalid YAML, non-spec keys, over the spec's length limits, missing required fields). A WARN is judgement, not law: the spec and the official validators disagree on several points, and this tool reports the disagreement instead of picking a side silently. Nothing you paste is stored - the check runs in one request and the upload is discarded.

v1 checks a single file. Whole-repo and CI usage is the same engine on the command line.
